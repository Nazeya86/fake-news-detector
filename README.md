Fake News Detection Web App
This project is a Machine Learning-based web application that detects whether a given news headline or content is real or fake. It uses Natural Language Processing (NLP) techniques and a supervised learning model to classify news articles.

The application is built with Python, trained using scikit-learn, and deployed using Flask for the backend and HTML/CSS for the frontend. The project is designed to help users verify the credibility of news content in a fast and accessible way.
